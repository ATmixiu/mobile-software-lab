# mobile-software-lab

移动软件开发实验仓库

## 仓库说明

### 实验3：高校新闻网

完成一个高校新闻微信小程序，在基础实验要求上进一步增加了新闻搜索、分类导航、浏览历史等功能。

主要功能包括：

- 新闻图片轮播
- 新闻列表展示
- 新闻详情查看
- 新闻收藏与取消收藏
- 新闻标题搜索
- 新闻分类导航
- 分类新闻页面
- 用户头像和昵称设置
- 退出登录
- 我的收藏
- 浏览历史
- 清空浏览历史
- 左右滑动返回
- 回到顶部
- 页面点击反馈
- 真机预览与调试
- 新闻图片压缩及上传包大小优化

实验过程中还对首页、新闻详情页、分类页和个人中心页面进行了样式优化。

- 源代码：[at3](./at3)
- 实验报告：[实验三报告](./实验3.md)
