### 实验3：高校新闻网
完成一个高校新闻微信小程序，在基础实验要求上进一步增加了新闻搜索、分类导航、浏览历史等功能。

主要功能包括：
- 新闻图片轮播
- 新闻列表展示
- 新闻详情查看
- 新闻收藏与取消收藏
- 新闻标题搜索
- 新闻分类导航
- 分类新闻页面
- 用户头像和昵称设置
- 退出登录
- 我的收藏
- 浏览历史
- 清空浏览历史
- 左右滑动返回
- 回到顶部
- 页面点击反馈
- 真机预览与调试
- 新闻图片压缩及上传包大小优化

实验过程中还对首页、新闻详情页、分类页和个人中心页面进行了样式优化。
- 源代码：[at3](./at3)
- 实验报告：[实验三报告](./实验3.md)

### 实验4：推箱子游戏
完成推箱子小游戏的页面布局、关卡逻辑与交互功能实现。
- 源代码：[at4](./at4)
- 实验报告：[实验四报告](./实验4.md)

### 实验5：HarmonyOS 科学计算器
基于 HarmonyOS ArkTS 开发的科学计算器应用，实现基础四则运算、科学函数计算、历史记录、计算过程查看、自定义函数绘图、深浅主题切换等功能。

主要功能包括：
- 基础四则运算与括号优先级
- sin/cos/tan 等三角函数（DEG/RAD 切换）
- 阶乘、幂运算、对数等科学计算
- 计算错误捕获与恢复
- 最近 20 条计算历史记录
- 计算过程分步查看
- 自定义函数表达式绘图
- 深色 / 浅色主题切换
- 大数字千位分隔与科学计数法

- 源代码：[at5](./at5)
- 实验报告：[实验五报告](./实验5.md)
